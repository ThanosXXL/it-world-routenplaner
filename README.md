# IT-WORLD Routenplaner

Framework-freie PWA (HTML/CSS/JS) zur Tourenplanung mit Fahrmodus, Sprachansagen und Offline-Karte.
Alle Daten bleiben auf dem Gerät. Bauen: `pip install fonttools brotli`, dann `python build.py && python pkg_build.py && python build_inst.py`.
Siehe `LIESMICH-WEITERARBEITEN.md`.
